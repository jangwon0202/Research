**레이 캐스팅** - 반직선 사용
**데카르트 좌표계**** - y축이 위쪽을 향하는 일반적으로 사용하는 좌표계
+ 연속된 실수를 사용
**스크린 좌표계** - y축이 아래쪽으로 향하는 모니터에서 사용하는 좌표계 
+ 이산적인 정수를 사용(0부터 해상도 크기까지)
+ 화면에 표현하려면 색상이 함께 지정되어야 함
**픽셀** - 스크린 좌표와 색상에 대응하는 화면의 구성요소
**픽셀화** - 실수로 표현된 벡터 좌표를 정수로 변환 후 색상을 부여하는 과정
**클리핑** - 화면(뷰포트/카메라 시야) 영역을 벗어나는 물체의 일부분을 잘라내어 버리는 연산
