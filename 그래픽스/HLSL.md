# 2. 셰이더 자료형

(1) **half4** - half 숫자 4개를 가진 자료형
```
half4 result = half4(1.0, 0.0, 0.0, 0.5);
```
result 안에 숫자 네 개(1.0, 0.0, 0.0, 0.5)가 들어감
색으로 사용하는 상황이면 각각 (R, G, B, A)로 해석하며 A는 **알파**로 투명도에 쓰임

```
float3 color = float3(0.25, 0.85, 1.0);
half alpha = 0.5;

half4 result = half4(color, alpha);
```
이렇게도 가능

# 3. **정밀도**

- 숫자를 얼마나 촘촘하기 구별하고 표현할 수 있는지
- **자료형**이 정밀도를 정함
- 연산 속도, 메모리 대역폭, 전력 소모, 화질에 영향을 줌

| 항목          | 정밀도가 영향을 주는 방식                                                                 |
| ----------- | ------------------------------------------------------------------------------ |
| **연산 속도**   | GPU가 16비트 연산을 효율적으로 지원하면 `half` 계산이 유리할 수 있으며<br>GPU나 컴파일 결과에 따라 차이가 없을 수도 있음. |
| **메모리 대역폭** | **실제로 저장하거나 읽어 오는 데이터**가 작아지면 한 번에 더 많은 데이터를 옮길 수 있음.                          |
| **전력 소모**   | 작은 자료형으로 연산과 데이터 이동이 줄어들면 전력을 덜 쓸 수 있어. 특히 모바일 GPU에서 고려하는 이유 중 하나.             |
| **시각적 품질**  | 정밀도가 부족하면 가까운 숫자를 구별하지 못해 색이 계단처럼 변하거나, 위치가 떨리는 등의 **아티팩트**가 생길 수 있음.          |

```
float x;        // 숫자 하나
float2 uv;      // 숫자 두 개
float3 center;  // 숫자 세 개
float4 data;    // 숫자 네 개

half alpha;     // half 숫자 하나
half3 rgb;      // half 숫자 세 개
half4 rgba;     // half 숫자 네 개
```
